# 🧮 Basic Calculator

A simple, responsive, and interactive **Basic Calculator** built using **HTML5, CSS3, and JavaScript**.

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal number support
- 🧹 Clear (`C`) button
- 🟰 Equals (`=`) button
- ⚠️ Division-by-zero error handling
- ✨ Modern glassmorphism-inspired UI
- 📱 Responsive design
- 🖱️ Hover and click animations

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling, animations, and responsive design
- **JavaScript** – Calculator logic and user interactions
